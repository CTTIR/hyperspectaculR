# Package index

## Compositions

Each of these needs the spectral axis: none could be produced from a
single wavelength. Every one returns a ggplot and captions the contrast
stretch it applied.

- [`hsa_mandala()`](https://cttir.github.io/hyperspectaculR/reference/hsa_mandala.md)
  : Radial Spectral Mandala
- [`hsa_spectral_flux()`](https://cttir.github.io/hyperspectaculR/reference/hsa_spectral_flux.md)
  : Cumulative Spectral Change
- [`hsa_fusion()`](https://cttir.github.io/hyperspectaculR/reference/hsa_fusion.md)
  : Multi-Band Spectral Fusion
- [`hsa_spectral_density()`](https://cttir.github.io/hyperspectaculR/reference/hsa_spectral_density.md)
  : Spectral Density

## Appearance

A theme for image panels, and colour ramps restricted to those that are
monotonic in lightness so ordering survives greyscale printing.

- [`hsa_theme()`](https://cttir.github.io/hyperspectaculR/reference/hsa_theme.md)
  : A Theme for Hyperspectral Figures
- [`hsa_palette()`](https://cttir.github.io/hyperspectaculR/reference/hsa_palette.md)
  : Perceptually Uniform Palettes for Spectral Imagery

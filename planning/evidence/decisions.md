The implementation adopts the following decisions from the audit and review process. They describe the prepared 0.2.0 candidate; publication and instrument interpretation remain separate decisions.

| Decision | Reason | Consequence if unsuitable |
|---|---|---|
| Work on an isolated feature branch and preserve the original planning files. | Keep implementation and package-build artifacts separate from the reviewed baseline. | The feature branch can be revised without changing the shared main branch. |
| Use strict propagation for required image observations; expose available-case fusion explicitly. | Missing channels must not become fabricated opaque measurements, and a default quantity should use the same selected bands at each pixel. | Existing incomplete data may produce fewer visible pixels; callers can choose available-case fusion and inspect contribution summaries. |
| Retain summary-only contribution metadata for each available-case fusion channel. | Selected-band count, minimum/maximum contributors, complete-pixel count and no-contributor-pixel count disclose changing participation without storing a full spatial count map. | Individual pixel denominators cannot be recovered from provenance; callers needing them must calculate them from the source data and mask. |
| Give unscaled images an explicit default display domain [0, 1], preserve raw values, and reject values outside a supplied raw domain. | A colour constructor needs a known range; silently learning a different domain for each image undermines comparison. | Callers with counts or another calibrated scale must supply appropriate display limits. |
| Reject invalid or unordered wavelength metadata and label missing coordinates as band indices. | Silent recycling, reordering and nanometre labels can change the scientific meaning. | Some previously accepted inputs now fail until data and metadata are corrected together upstream. |
| Divide implementation into image contracts, exact density, spectral extensions, publication/checks and final evidence, each with a scoped review before the final whole-branch review. | Shared numerical interfaces need to stabilize before dependent work. | A cross-cutting finding may reopen an earlier contract and add rework. |
| Include physical flux, wavelength-target mandalas, RMS spectral slope and within-pixel quartiles after independent definitions and fixtures pass. Mark the two new summary renderers experimental. | The requested full roadmap includes evaluating these additions; synthetic experiments establish descriptive meaning and limitations. | API details may evolve, and the results must not be read as physiological measures, uncertainty estimates or universally sampling-invariant quantities. |
| Use 50 realizations per noisy condition in the illustrative sampling study. | Distributions across conditions are more informative than a single favourable realization; the full experiment has 8,080 records. | These simulations are not calibrated uncertainty estimates or evidence for a particular instrument. |
| Keep the organization-wide reusable CI and add package-specific exact-minimum checks. Pin a compatible optional patchwork version for ggplot2 3.4.0. | The shared moving-oldrel matrix does not establish exact R 4.1.0 support; current patchwork cannot load with the selected old ggplot2. | Dependency pins need maintenance; the selected combination does not claim every possible dependency combination works. |
| Extend the memory contract to plot, aesthetic and callback environments, not only provenance fields. | Review found that apparently compact plots retained source cubes through lexical environments. | Omitting any retention route would keep large data alive and invalidate returned-object memory claims. |
| Preserve exact density calculations and use band-sized buffers for fixed limits without global references. Keep exact global percentile selection explicit about its full-population storage. | The measured large-input case can avoid full-cube working arrays on the fixed path without approximation. | Automatic percentiles remain more expensive; callers needing bounded working storage should choose explicit limits. |
| Preserve representable extreme and subnormal spectral results even when arithmetic safeguards cost runtime. Use a guarded ordinary path only where it retains the contract. | Fast arithmetic that rounds a representable final result to zero or overflows early is numerically wrong. | Unusual inputs may use a slower fallback; performance evidence must distinguish that cost from ordinary inputs. |

The scientific scope is descriptive rendering and diagnostics. Separate implementation and mathematical review passes checked definitions, examples and numerical behavior. No external instrument calibration or domain-validation study was performed.
